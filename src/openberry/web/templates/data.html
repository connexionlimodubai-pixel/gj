Restore a backup

Restoring replaces all your data with the backup's. OpenBerry checks the backup first, and keeps a copy of your current data.

{% if restore.docker %}
  1. In the folder with docker-compose.yml, run these, with the backup's file name: 
    {% for line in restore.steps %}{{ line }}
{% endfor %}
    {{ m.copy_button("#restore-cmd", "Copy", "btn btn-sm btn-ghost") }}
  2. Copy a downloaded backup into the volume's backups folder first if it isn't there.
{% else %}
  1. Close OpenBerry, and quit Claude Desktop (right-click its icon by the clock, Quit).
  2. Run this in a terminal (Command Prompt on Windows), with the path of your backup file: 
    {{ restore.line }}
    {{ m.copy_button("#restore-cmd", "Copy", "btn btn-sm btn-ghost") }}

    {% endif %}
  3. Open OpenBerry again.
{% endif %}
