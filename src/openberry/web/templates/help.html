{{ m.icon("zap") }}Sources set up on the server

Most sources only need the company profile. These also need a setting in the server's .env file (restart OpenBerry after changing it):

  • Reddit ({{ "set up" if reddit_ready else "not set up" }}): create a Reddit API app and set REDDIT_CLIENT_ID, REDDIT_CLIENT_SECRET and REDDIT_USERNAME. Commercial use needs Reddit's agreement.
  • SEC EDGAR: OPENBERRY_CONTACT_EMAIL, or a contact e-mail in the company profile (the SEC asks for one).
  • GitHub (optional): GITHUB_TOKEN raises the limit from 60 to 5,000 requests an hour.
