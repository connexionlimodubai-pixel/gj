{{ m.icon("chevron-right", 14) }}How to get a key
  1. Open the Google Cloud console (console.cloud.google.com) and create a project.
  2. Set up billing. Google asks for a card, but the first {{ free_per_month|compact }} searches each month are free.
  3. Turn on Places API (New) for the project.
  4. Create an API key under APIs & Services, Credentials. Restrict it to Places API (New).
  5. Paste the key here and save.
